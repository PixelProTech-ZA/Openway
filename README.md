# Openway

No matric. Still a future. A PixelProTech Solutions product.

Prototype PWA (design v2). All vacancies are **test data**. No job provider is connected yet.

## Files (flat, no subfolders)
- `index.html` the whole app (HTML, CSS, JS)
- `manifest.webmanifest` install details
- `sw.js` offline cache. Change `VERSION` whenever you change any file
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png`, `favicon.ico`
- `.nojekyll` tells GitHub Pages to serve files as they are

## Publish on GitHub Pages
1. Create a repository and upload every file in this folder to the top level (include `.nojekyll`).
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Open `https://<user>.github.io/<repo>/` on a phone over HTTPS and choose Install / Add to Home Screen.

All paths are relative, so it works at a repository sub-path or a custom domain.
